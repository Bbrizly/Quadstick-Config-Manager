The clinician layer

The profile is only half the story.

The free app makes a good setup. Clinic remembers why it works and what changed, so the next appointment does not start from scratch.

↕

Vertical: one client over time.

Sessions, notes, immutable profile snapshots, outcomes and goals form one chronological record instead of a folder archaeology problem.

↔

Horizontal: your own prior work.

Ask what helped a similar client. Matching is explained by level, goals, activity, input method and device context rather than a magic score.

✓

Context → change → outcome.

A tiny structured outcome—better, same, worse or not assessed—turns old sessions into a useful knowledge base without pretending to be a medical recommendation engine.

Built for trust

A folder, not another cloud.

The paid layer is intentionally boring where hospitals need it to be: one clinician's local roster, no account, no pooled dataset and no mystery sync protocol.

01

No network in Clinic.

No community catalog, Google sign-in, telemetry or background HTTP client in the clinic build.

02

Your folder is the boundary.

The site chooses the folder and its existing FileVault, BitLocker, permissions and backup policy protect it.

03

Your data stays yours.

An expired or missing licence can make the roster read-only, but it never blocks viewing or exporting the clinician's own records.
