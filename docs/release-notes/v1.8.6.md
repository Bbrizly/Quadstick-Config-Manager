# Side tube on new modes and a reference sheet

- Adding a mode now maps the side tube: sip goes to the next mode, puff to the one before. A copied mode gets the same two rows if it has no way to switch and its side tube is free. Thanks to Drew Redepenning.
- If adding a mode leaves another mode with no way to switch, and its side tube is free, that mode gets the rows too, and the app says so.
- Print a reference sheet: a button on the profile toolbar saves a table of the controls in each mode, opens it in your browser, and you print from there.
- The app now warns when a mode is past the 16 the device supports.
