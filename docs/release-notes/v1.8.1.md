# Adaptive Profiles integration

This release connects QuadStick Config Manager to the new public Adaptive Profiles registry.

## Open profiles from the web

Adaptive Profiles profile pages can now hand a reviewed community profile to QCM with:

```text
qcm://profile/<registry-id>
```

QCM registers the `qcm://` protocol on Windows and macOS.

## Safe by design

A web link never installs anything directly to a QuadStick.

When QCM receives a profile link it:

1. loads the public `Bbrizly/Adaptive-Profiles` registry index
2. resolves the exact accepted profile ID
3. downloads the reviewed GitHub `profile.csv` snapshot
4. verifies the snapshot against the registry SHA-256
5. opens the normal QCM editor/review flow
6. leaves save/install entirely up to the user

QCM caches the last valid registry index and verified profile snapshots so previously resolved profiles can remain usable during temporary network outages.

## Hardened deep links

The protocol parser accepts only the canonical route:

```text
qcm://profile/<lowercase-registry-id>
```

Traversal, encoded traversal, query strings, fragments, userinfo, extra path segments, malformed IDs, unsupported registry shapes, duplicate IDs, invalid Google provenance hosts, oversized responses, invalid UTF-8, and snapshot hash mismatches are rejected.

## Architecture

The profile registry, website, game database, device definitions, and contribution automation live in the standalone `Bbrizly/Adaptive-Profiles` repository. QCM remains only a client of that public registry.
