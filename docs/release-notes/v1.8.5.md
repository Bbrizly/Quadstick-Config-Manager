- Function numbers under each output now read "first number" and "second number", then the default, in all 13 languages. The 1 to 16383 ranges are gone. Thanks to Drew Redepenning's sheet.
- A ? next to the emulation mode, in the device settings and in a profile's preferences, says which mode each console adapter needs: mode 0 for Mayflash Magic-X, Magic-S, Magic-NS and Brook XE 2 / XB 3; mode 4 with the Titan Two setting on for Brook FGC 2, P5 and P5s.
- Importing a Google Sheet now says it is a copy. Saving never changed the sheet.
- Linux: profile files with upper case names (GTA5.CSV) show up again.
- Mac and Linux: the QuadStick drive shows its name, not its mount path.
